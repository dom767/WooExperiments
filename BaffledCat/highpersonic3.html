The story

I created Highpersonic as an audio visualiser for Winamp back in 1998. It was my first real application using DirectX5, and was a great learning experience at the time.

There's a bit of history too with a friend of mine who also wrote a Winamp plugin. We shared a lot of ideas and code, and we both ended up in computer games after university. Tripex3 is still available on GitHub if you take a look.

For my own reimagining I've taken some of the original ideas from Highpersonic 1, some incomplete effects that I developed for Highpersonic 2, which was never released, and merged them together into a new application called Highpersonic 3.

As a sign of the times, Highpersonic 3 is now a browser-based application, with all of the code built using Cursor, where I'm generally only here for steering purposes! I guess that's the future now.

I hope you get some enjoyment out of this version, and if there's anything you'd like adding, drop me a line!
